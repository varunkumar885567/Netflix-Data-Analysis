# Netflix Data Analysis and Visualization

## Project Overview

This project performs data analysis and visualization on the Netflix titles dataset using Python.

The main objective of this project is to understand Netflix content based on movies, TV shows, countries, release years, ratings and movie duration.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses the Netflix Titles dataset containing information about movies and TV shows available on Netflix.

## Analysis Performed

- Movies vs TV Shows analysis
- Content ratings distribution
- Top 10 countries with Netflix content
- Movie duration analysis
- Release year analysis
- Data visualization using different charts

## Visualizations

The project includes:

- Movies vs TV Shows
- Content Ratings Pie Chart
- Movie Duration Histogram
- Release Year Scatter Plot
- Top 10 Countries

## Project Files

- `Netflix_Data_Analysis.ipynb` - Main Jupyter Notebook
- `netflix_titles.csv` - Netflix dataset
- PNG files - Generated visualizations

## Conclusion

This project provides insights into Netflix's content library and demonstrates how Python can be used for data cleaning, analysis and visualization.
